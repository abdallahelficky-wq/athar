# أثر المتجر الإلكتروني — Android app

تطبيق العملاء العام لمتاجر أثر: غلاف WebView حول دليل المتاجر العام (`/store`) والمتاجر نفسها
(`frontend/src/store`، الرابط في `app/build.gradle.kts` → `STORE_URL`). ليس خاصاً بشركة: يفتح الدليل، ومنه
يدخل العميل أي متجر وافقت شركته على الإدراج (بيانات الشركة ← المتجر الإلكتروني ← «إدراج المتجر في الدليل»).
لا منطق أعمال في التطبيق؛ أي تغيير في المتاجر يظهر فيه فوراً بلا إصدار جديد.

- يبقى داخل التطبيق كل ما تحت `/store`؛ واتساب والاتصال وأي رابط خارجي تُفتَح في تطبيقاتها، ونظام أثر
  المحاسبي لا يُفتَح داخله.
- السلة ورمز دخول العميل في `localStorage` (لكل متجر على حدة) فيبقيان بين مرات الفتح.
- صلاحية واحدة: الإنترنت. بلا جسر JavaScript.
- الأيقونة شعار أثر (نفس طبقات أيقونة تطبيق نقطة البيع، `assets/brand/generate_android_icons.py`).

البناء والتوقيع عبر `.github/workflows/android-store-build.yml` بالسكربت المشترك
`.github/scripts/android-signed-build.sh`: APK debug في كل دفعة تلمس `android-store/`، وإصدار موقَّع يدوياً
من بيئة `android-release`.
