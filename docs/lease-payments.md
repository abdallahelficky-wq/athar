# موديول الإيجارات (عقود، جدول دفعات، قيود آلية)

الشاشة: «عقود الإيجار» في القائمة الرئيسية. الكود: `src/modules/leaseContracts`، الحسابات الخالصة في `src/lib/leaseSchedule.ts`، والواجهة
`frontend/src/wired/leases/LeasesTab.jsx`.

## المعالجة المحاسبية

| الحدث | القيد | المصدر |
|---|---|---|
| تأكيد سداد دفعة | مدين «إيجار مدفوع مقدماً» بالصافي + مدين «ضريبة القيمة المضافة - مدخلات» بالضريبة / دائن حساب السداد بالإجمالي، بتاريخ السداد | `lease_payment` |
| إطفاء شهر | لكل دفعة مسدَّدة: مدين مصروف الإيجار / دائن «إيجار مدفوع مقدماً» بنصيب الشهر، قيد واحد للشركة بتاريخ آخر يوم في الشهر | `lease_amortization` |

- العقد «شامل الضريبة» تُستخرج ضريبته من مبلغ الدفعة بنسبة الشركة (المبلغ × 15 ÷ 115)؛ «بدون ضريبة» المبلغ كله إيجار.
- نصيب الشهر: فترة أشهر كاملة تُقسَم بالتساوي، وفترة تبدأ أو تنتهي وسط الشهر تُوزَّع بعدد الأيام. المجموع يساوي الصافي بالهللة.
- الإطفاء تراكمي: دفعة سُدِّدت متأخرة تلحق أشهرها الفائتة في أول إطفاء بعد سدادها. الدفعة غير المسدَّدة لا تُطفأ وتظهر تنبيهاً.
- «سماح»: دفعة لا تُدفع (فترة سماح، محطة متوقفة) — لا قيد ولا إطفاء.
- «سُدِّدت خارج النظام»: تُسجَّل مسدَّدة بلا قيد سداد، وتُطفأ ابتداءً من «أول شهر يُطفأ في النظام»؛ ما قبله يُعَد مصروفاً في الدفاتر السابقة.
- حسابا العقد اختياريان؛ الفارغ يُحَل بالاسم القياسي في شجرة الشركة: «إيجارات مدفوعة مقدماً» و«إيجار مواقع/فروع».

## التصحيح

- عكس السداد من الشاشة: قيد عكسي بنفس المصدر، وتعود الدفعة بانتظار السداد. مرفوض ما دام أُطفئ منها شيء.
- إزالة الإطفاء: آخر شهر مرحَّل فقط، بالرقم السري لفك الترحيل وصلاحية «فك الترحيل».
- القيدان مقفلان في شاشة القيود: لا عكس ولا فك ترحيل ولا تعديل ولا حذف ولا قيد مرآة (`assertNotStationShiftEntry`).

## ملف الاستيراد (JSON)

زر «استيراد عقود» يقبل ملف JSON بهذه الصيغة. الاستيراد كله أو لا شيء، وعنوان عقد موجود في الشركة يرفض الملف كله.

```json
{
  "contracts": [
    {
      "title": "محطة المثال",
      "counterparty": "اسم المؤجر",
      "vatMode": "inclusive",
      "startDate": "2027-01-01",
      "endDate": "2027-12-31",
      "costCenterName": null,
      "paymentAmount": 57500,
      "paymentEveryMonths": 6,
      "firstDueDate": "2027-01-01",
      "notes": null,
      "payments": [
        { "dueDate": "2027-01-01", "periodFrom": "2027-01-01", "periodTo": "2027-06-30", "amount": 57500 },
        { "dueDate": "2027-07-01", "periodFrom": "2027-07-01", "periodTo": "2027-12-31", "amount": 57500, "status": "waived", "note": "سماح" }
      ]
    }
  ]
}
```

- `vatMode`: `none` أو `inclusive`. `status`: `due` (الافتراضي) أو `waived` أو `paid_external` (مع `paidOn`، واختيارياً `amortizeFromMonth` بصيغة `YYYY-MM`).
- `costCenterName` يُطابَق باسم مركز تكلفة في الشركة (أو مشترك على مستوى المستأجر)؛ اسم غير موجود يرفض الملف.
